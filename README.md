# Laboratório - Code Smells e Refatoração

Repositório contendo os exercícios do Laboratório 8.

O objetivo deste laboratório é identificar problemas de código (Code Smells) e aplicar técnicas de refatoração para melhorar:
- legibilidade
- manutenção
- encapsulamento
- organização
- orientação a objetos
